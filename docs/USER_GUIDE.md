# 充电手账使用指南

适用于 v1.3.2。下载：[最新安装包](https://github.com/tonyai12138-cmd/charge-ledger/releases/latest/download/ChargeLedger.apk)。

## 安装与升级

在手机打开 APK，按系统提示允许安装。已有旧版时直接更新，不要先卸载。正式包使用相同包名与签名，升级保留本地账本；建议升级前先导出 JSON 备份。首次安装显示空账本。

## 记录一笔费用

1. 首页点击“记录充电费用”，或明细点击固定的“+”。
2. 输入实际充电金额，选择日常或差旅。时间可选择完整时间、仅日期或仅月份。
3. 电量不知道就留空。可选填地点、行程、运营商、备注、停车费等。
4. 有计费电量时自动计算综合单价。定位会补充附近地址，站名仍需确认；拒绝定位也能使用。

差旅行程中多次充电只有一个总额时，选择行程合计，仅填月份也可以。之后补齐各笔明细时，先把对应合计移入回收站，避免重复统计。

## 明细与统计

明细可按日期、用途、关键词筛选，点击记录可查看、编辑或删除。误删可在回收站恢复。

统计可选日、周、月、季、年，以及全部 / 日常 / 差旅。费用、电量、均价与条目数有环比：红色和上箭头表示增加，绿色和下箭头表示减少。尚未结束的周期会提示；上期为 0 不显示无限百分比。仅月份费用只纳入月、季、年。

费用缺电量不影响支出，但不会参加单价计算；加权均价使用有电量样本。条目数量可能包含行程合计，不能直接视为实际充电次数。

## 历史费用 JSON

“我的 → 追加导入历史费用”会先展示预览，确认后追加，不替换现有账本。相同编号且内容一致的记录会跳过；编号相同但内容不一致时整批中止。

下面仅为合成示例，不包含真实用户记录：

```json
{
  "format": "charge-ledger-legacy-expenses",
  "version": 1,
  "currency": "CNY",
  "records": [
    {
      "id": "example-daily-2026-10-01",
      "datePrecision": "day",
      "date": "2026-10-01",
      "monthKey": "2026-10",
      "time": null,
      "recordKind": "charging_expense",
      "category": "daily",
      "amountCents": 1200,
      "energyMilli": null,
      "station": null,
      "note": "示例：电量未记录"
    },
    {
      "id": "example-trip-2026-10",
      "datePrecision": "month",
      "date": null,
      "monthKey": "2026-10",
      "time": null,
      "recordKind": "trip_expense_summary",
      "category": "business",
      "amountCents": 5000,
      "energyMilli": null,
      "station": null,
      "trip": "示例城市甲 → 示例城市乙",
      "note": "示例：行程多次充电合计"
    }
  ]
}
```

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定唯一编号；再次导入沿用原编号 |
| `amountCents` | 整数分，例如 1200 表示 12.00 元 |
| `energyMilli` | 整数千分之一度，例如 12500 表示 12.500 度；不知道用 null |
| `datePrecision` | `day` 为仅日期，`month` 为仅月份 |
| `date` / `monthKey` | 日期 YYYY-MM-DD / 月份 YYYY-MM，两者须对应 |
| `time` | 未记录具体时间用 null |
| `category` | `daily` 日常，`business` 差旅 |
| `recordKind` | `charging_expense` 单笔费用，`trip_expense_summary` 行程合计 |

完整 schema-1 备份也能追加其中的记录。完整时间与旧版字段的构造以 App 导出的 JSON 为准。

## 导出与备份

- Markdown：用于复制、分享或向外部 AI 分析，可按时间和用途选择范围，可隐藏地点、行程和备注。App 不提供 AI 功能。
- JSON：完整保存记录、设置和回收站。恢复前有确认，完整恢复会替换当前账本；历史费用请使用追加导入入口。

系统保存窗口可选择文件位置。手机卸载、清除数据或迁移前，请备份到自己能找到的目录。

## 电价与界面设置

电价页提供省份、区域、季节与文件范围的参考说明；到站仍以站点订单中的电费、服务费、停车费及优惠为准，内置资料不会自动联网更新。

“车辆与预算”可设置车辆、月预算和界面动画。减少动画时开屏保留静态品牌展示，切换与浮层减少移动效果。左右滑动可切换主页面，横向选择栏支持点击和拖动。
