# Commit attribution

For commits materially assisted by OpenAI Codex, keep the repository owner's
configured author and committer identity and append this standard trailer:

```text
Co-authored-by: Codex <codex@openai.com>
```

Use the GitHub-recognized co-author trailer rather than adding a contributor
paragraph to README. Do not rewrite published history or move release tags
solely to backfill attribution.
